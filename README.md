# ANALOG WBO C3 — Беспроводной индикатор состава смеси (AFR / Lambda)

Высокоточный автомобильный прибор на базе **ESP32-C3**, считывающий аналоговый сигнал **0–5 В** с контроллера широкополосного датчика кислорода (ШЛЗ Bosch LSU 4.9, например Innovate LC-2, AEM X-Series, 14Point7 Spartan 2/3, VEMS и др.) и передающий данные по **Bluetooth Low Energy (BLE)** на смартфон с ультранизкой задержкой.

---

## 🚀 Особенности проекта

- **Минимальная задержка (Low Latency)**: BLE Connection Interval 7.5–15 мс и передача пакетов со скоростью **30–40 Гц**.
- **Высокая точность**:
  - Аппаратная eFuse-калибровка АЦП ESP32-C3 (`analogReadMilliVolts()`).
  - Быстрый аппаратный оверсэмплинг (32 выборки за цикл).
  - Адаптивный фильтр EMA: мгновенный отклик при резком газе/отсечке и сглаживание шума на установившемся режиме.
- **Готовый Web Bluetooth Dashboard**:
  - Автономная HTML5 страница: не требует установки сторонних приложений из магазинов.
  - Работает прямо в браузере **Google Chrome (Android)** или **Bluefy (iOS)**.
  - Спортивный дизайн со шкалой AFR, цифровым дисплеем, цветовой индикацией (Rich / Stoich / Lean), графиком в реальном времени и защитой от засыпания экрана (Wake Lock API).
- **100% совместимость со сторонними приложениями**:
  - Используется стандартный профиль **Nordic UART Service (NUS)**.
  - Совместим с приложениями *Serial Bluetooth Terminal*, *nRF Connect*, *nRF Toolbox*.

## 📐 Схема подключения (Hardware Wiring)

> ⚠️ **ВНИМАНИЕ!** Вход АЦП ESP32-C3 рассчитан максимум на 3.3 В (оптимальный линейный диапазон АЦП — до 2.5–3.0 В). **Подача сигнала 5 В напрямую сожжет пин микроконтроллера!** Подключение выполняется строго через резистивный делитель.

### Резистивный делитель 1:2 (10 кОм + 10 кОм)

```
[ WBO Контроллер 0-5V Выход ] 
               │
              [R1: 10 кОм]
               │
               ├───► К пину GPIO 0 (ADC1_CH0) на ESP32-C3
               │
              [R2: 10 кОм]
               │
               ▼
[ Общая земля (GND) ШЛЗ и ESP32-C3 ]
```

- **R1** (10 кОм 1%): между аналоговым выходом 0-5V контроллера ШЛЗ и пином **GPIO 0** ESP32-C3.
- **R2** (10 кОм 1%): между пином **GPIO 0** ESP32-C3 и контактом **GND**.
- **GND ШЛЗ и ESP32-C3**: обязательно соединить вместе!

*Расчет:* при 5.0 В на выходе контроллера на пине ESP32 будет ровно:
$$V_{adc} = 5.0 \times \frac{10}{10 + 10} = 2.50\text{ В}$$

## 💻 Загрузка скетча через Arduino IDE

1. **Подготовка Arduino IDE**:
   - Откройте **Arduino IDE**.
   - Перейдите в *Файл -> Настройки* и убедитесь, что добавлен URL плат ESP32:
     `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - В *Инструменты -> Платформа -> Менеджер плат* установите пакет **esp32** (Espressif Systems).

2. **Выбор платы**:
   - В меню *Инструменты -> Плата* выберите:
     - **ESP32C3 Dev Module** (или вашу модель, например *AirM2M CORE ESP32C3* / *ESP32-C3 SuperMini*).
   - Настройки порта и параметров (обычно по умолчанию):
     - *Upload Speed*: `921600` (или `460800`)
     - *USB CDC On Boot*: `Enabled` (если используете плату SuperMini с прямым USB Type-C).
     - *Flash Frequency*: `80MHz`
     - *Flash Mode*: `QIO` / `DIO`

3. **Прошивка**:
   - Откройте файл `ANALOG_WBO_C3.ino` (или `ANALOG WBO C3.ino`).
   - Нажмите кнопку **Загрузка (Upload)**.

## 📱 Как пользоваться на смартфоне

### Вариант 1: Web Bluetooth Dashboard (Рекомендуется)

1. Файл `web_dashboard/index.html` содержит готовый веб-интерфейс со шкалой.
2. Как запустить на телефоне:
   - **Способ А (Самый простой)**: Скопируйте файл на любой хостинг с HTTPS (например, GitHub Pages, Vercel, Netlify) либо запустите простой локальный веб-сервер в домашней сети. *(Web Bluetooth API в браузерах требует безопасного протокола HTTPS или localhost)*.
   - **Способ Б**: Загрузить на бесплатный GitHub Pages в свой репозиторий.
3. Откройте страницу в браузере:
   - **Android**: Google Chrome.
   - **iPhone / iPad**: Браузер **Bluefy** (бесплатно в App Store, поддерживает Web Bluetooth).
4. Нажмите большую кнопку **⚡ ПОДКЛЮЧИТЬ ДАТЧИК**.
5. В открывшемся списке выберите устройство **WBO_AFR_C3** — показометр мгновенно оживет и начнет отображать реальные параметры смеси.

### Вариант 2: Приложение "Serial Bluetooth Terminal" (Android)

1. Установите бесплатное приложение **Serial Bluetooth Terminal** (автор Kai Morich) из Google Play.
2. В меню слева выберите **Devices -> Bluetooth LE**.
3. Нажмите поиск и выберите **WBO_AFR_C3**.
4. Терминал подключится к сервису Nordic UART и начнет выводить значения в формате:
   `14.70,2.35,1.00` *(AFR, Вольты, Lambda)* с частотой 30–40 раз в секунду.

## ⚙️ Точная калибровка (если требуется)

В начале скетча `ANALOG_WBO_C3.ino` находятся удобные константы:

```cpp
#define ADC_PIN                 0        // Пин АЦП (GPIO0)
#define VOLTAGE_DIVIDER_RATIO   2.000f   // Коэффициент делителя: (R1+R2)/R2
#define VOLTAGE_OFFSET_V        0.000f   // Смещение нуля (разница потенциалов масс)
#define BLE_UPDATE_INTERVAL_MS  25       // Период отправки (25 мс = 40 Гц)
```

- Если ваши резисторы имеют погрешность (например, 9.9 кОм и 10.1 кОм), можно замерить входное и выходное напряжение делителя мультиметром и выставить реальный коэффициент в `VOLTAGE_DIVIDER_RATIO`.
- Если контроллер ШЛЗ при калибровочном значении (например, 0.0 В в режиме калибровки) показывает небольшое смещение из-за разницы масс в автомобиле, скорректируйте `VOLTAGE_OFFSET_V`.
